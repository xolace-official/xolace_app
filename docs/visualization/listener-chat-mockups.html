2 · Chat — request/pending and active thread
The eng review added a request/accept flow provisionally (pending confirmation from 5 of 6 ambassadors) but didn't specify what the requester sees while waiting. Also added here: a manual "talk to someone now" escape hatch inside the live thread — the plan explicitly defers automated escalation detection to v2, but ships zero UI mitigation for the gap in the meantime. That's a bigger miss than the doc treats it as.
