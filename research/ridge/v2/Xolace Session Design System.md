\# Xolace Session Design System

Version: 0.1

Status: Product Design

\# Philosophy

The interface should disappear.

The user should never remember the UI.

They should remember:

• what they realised

• what they felt

• what they carried away

Every design decision should reduce emotional effort.

\---

\# Emotional Design Principles

The interface should feel

• Quiet

• Warm

• Spacious

• Honest

• Gentle

Never

• Busy

• Clinical

• Gamified

• Corporate

• Productivity-focused

\---

\# Visual Identity

Keywords

Night

Warm Light

Paper

Reflection

Breathing

Stillness

The UI should feel like sitting in a quiet room at night.

\---

\# Layout System

Use an 8pt spacing system.

Major sections

48px

Cards

24px

Between paragraphs

20px

Between heading and content

16px

Nothing should ever feel crowded.

\---

\# Grid

Single Column

Mobile First

Maximum readable width

Everything centred.

\---

\# Border Radius

Cards

24px

Buttons

18px

Input

20px

Emotion Chips

999px

Large soft corners.

No sharp edges.

\---

\# Colour Philosophy

Background

Deep charcoal

not black

Primary Surface

Slightly lighter charcoal

Accent

Warm cream

Muted lavender

Soft sage

Never neon.

Never bright blue.

Never harsh red.

\---

\# Typography

Primary Font

Inter

Headings

Bold

Large

Body

Regular

Comfortable reading width

Line height

1.6

Everything should feel readable.

\---

\# Icons

Minimal

Rounded

Outlined

No filled icon sets.

No decorative icons.

Only functional icons.

\---

\# Buttons

Primary

Soft filled

Rounded

Large touch area

Secondary

Text only

Never more visually dominant than reflection.

\---

\# Cards

Cards should float gently.

No heavy shadows.

Very subtle elevation.

The card should almost disappear into the background.

\---

\# Reflection Card

Purpose

Create emotional focus.

Contains

• Mirror

Nothing else.

No distractions.

\---

\# Path Card

Purpose

Transition back into life.

Contains

• Title

• Reflection

• Action

No statistics.

No graphs.

\---

\# Insight Cards

Should feel like journal entries.

Not dashboard widgets.

Every card tells one story.

Never multiple stories.

\---

\# Animation Philosophy

Everything should feel slow.

Fade

Opacity

Blur

Scale

No bounce.

No spring.

No confetti.

Animation should never ask for attention.

\---

\# Animation Timing

Micro

150ms

Cards

250ms

Screen Transition

350ms

Reflection Appearance

500ms

Everything should breathe.

\---

\# Haptics

Very subtle.

Only

Session Started

Mirror Ready

Path Ready

No excessive vibration.

\---

\# Loading

Loading should never feel technical.

Instead of

Loading...

Use

Taking a moment...

or

Reflecting...

or simply animate the surface.

\---

\# AI Behaviour

The AI should never sound certain.

Prefer

"It seems..."

"It sounds like..."

"I wonder if..."

Avoid

"You are..."

"You definitely..."

"You always..."

\---

\# Empty States

Never empty.

Always reassuring.

Example

"The more you reflect,

the more patterns begin to appear."

\---

\# Error States

Never expose technical language.

Never say

Server Error

Instead

"We couldn't finish reflecting just now.

Let's try again."

\---

\# Accessibility

Minimum touch target

48px

High contrast

Readable typography

Support Dynamic Type

Reduced Motion support

\---

\# Design Rules

Every screen should answer one question.

Every card should communicate one idea.

Every interaction should have one purpose.

If a screen contains more than one emotional objective...

Split it.

\---

\# Things We Never Build

XP

Leaderboards

Badges

Points

Levels

Achievements

Productivity metrics

Mood Scores

Engagement tricks

\---

\# Things We Always Build

Reflection

Understanding

Clarity

Patterns

Memory

Connection

Gentle guidance

\---

\# The Xolace Feeling

When someone closes the app...

they shouldn't think

"That was a nice interface."

They should think

"I understand myself a little better."

That is the product.

The interface simply gets out of the way.
