Session Experience Map
======================

I'd make this the source of truth for everyone on the team 😤😤.

Purpose
=======

The session should not end when the Mirror ends.

The session ends when the user leaves with something meaningful.

The goal is to bridge:

> Understanding

↓

Action

without becoming therapy, coaching, or productivity.

Moment 1 — Expression
---------------------

Current screen.

Purpose:

Allow the user to express something they cannot yet fully explain.

Inputs:

*   Free text
    
*   Voice
    
*   Emotion chips
    

Output:

Raw emotional context.

Moment 2 — Mirror
-----------------

Purpose:

Help the user feel understood.

The Mirror should:

*   Reflect
    
*   Clarify
    
*   Name
    

Not advise.

Not solve.

Output:

A reflection.

Moment 3 — Confirmation
-----------------------

Current buttons:

*   That's it
    
*   Not quite
    
*   Say more
    

Purpose:

Confirm whether the Mirror reached the user's experience.

This becomes the AI's confidence signal.

Moment 4 — Detection (Invisible)
--------------------------------

The user never sees this.

The AI asks internally:

> "What is this person most likely missing right now?"

Examples:

*   Connection to self
    
*   Connection to patterns
    
*   Connection to another person
    
*   Connection to the present moment
    
*   Connection to hope
    

This is not shown.

Moment 5 — Connection (Invisible)
---------------------------------

Connection is not content.

Connection is classification.

It simply determines the user's primary need.

Moment 6 — Path (Visible)
-------------------------

This is the only new visible experience.

The Path is not another conversation.

It is one meaningful bridge back into real life.

The Path should always answer:

> "Given everything we've understood...

what is the smallest meaningful thing this person should leave with?"

Types of Path
-------------

Grounding

↓

Sit With This

Human Connection

↓

You're Not Alone

Perspective

↓

Reflective Question

Pattern Awareness

↓

Across your reflections...

Hope

↓

Take This With You

Every Path is different.

The structure remains the same.

Moment 7 — Close
----------------

The user leaves.

Not because they completed the app.

Because they completed the moment.

Success Metric
==============

A successful session is not

> "The user completed breathing."

Nor

> "The user shared anonymously."

A successful session is when the user leaves saying

> **"I know what I need right now."**

Key Principle
=============

This line should be highlighted in the document because I think it captures everything we've been discussing:

> **The intelligence of Xolace should come from its decisions, not from adding more screens.**
