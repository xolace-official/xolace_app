\# Session Wireframe Specification

Version: 0.1

Status: Product Design

Feature: Session V2

\---

\# Goal

Design a session experience that feels calm, uninterrupted and intelligent.

The interface should disappear.

The user should only remember:

\- what Xolace reflected

\- what Xolace left them with

\---

\# Overall Layout

Every screen shares the same design language.

Large margins.

Lots of breathing room.

Minimal visual noise.

Dark background.

Soft accent colours.

Nothing should compete with the content.

One action.

One exit.

Never overwhelm.
